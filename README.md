# 感謝を書き残すFlask_app

## アプリケーションの概要。
  - 感謝したくても出来ない人たちが気持ちを匿名で吐けるアプリケーション。
## アプリケーションで実装したこと。
  - 新規登録機能
  - ログイン、ログアウト機能(session)
  - アカウントを削除する機能。
  - ユーザー一覧ページの作成。
  - 簡単なマイページ（プロフィール）の作成。
  - プロフィールをアップデートする機能。
  - 感謝を投稿する機能。
  - 感謝一覧ページ作成。
## 開発環境
  - プログラミング言語はPythonです。
  - フレームワークはFlaskです。
  - データーベースには、SQLite3を使用しました。
  - HTMLは、ほぼBootstrapに頼っています。
## 細かいところ。
  - パスワード、メールアドレスは*モジュール re*で検証しています。
  - flashを多様（警告とか知らせとか）
  - sessionを使うことで再入力の手間を省きました。
  - ログインしていなくてもユーザー一覧と投稿一覧は見れる。
  - ログインしていないと投稿はできない。
